# Embargo

**Demo video (1:54, recorded on the Dell Pro Max GB10):** [media/embargo_demo.mp4](media/embargo_demo.mp4)


**Keeps controlled files inside the building.** Embargo is a local AI export-control officer: it stops weapons blueprints from leaving a defense supplier, even when someone crops the label off first.

Small defense machine shops send drawings to suppliers and customers every day. If one ITAR-controlled drawing reaches a foreign person without a license, that's a federal violation (Boeing settled for $51M in 2024, RTX for $200M). They can't paste the drawing into a cloud AI to check it, because uploading it *is* the leak. So Embargo runs on one box in the building (a Dell Pro Max with GB10), and the drawing never leaves.

The demo checks **defense drawings**. The same engine (recognise the file itself, check the recipient, require a second person, log everything) fits any data that legally can't leave: chip designs (EAR), patient records (HIPAA), genomic data, and government CUI. The sign-in page shows that range.

> **Disclosure.** The core engine, dataset generator, console and Slack bot were written on **Oct 24, 2026, the evening before the Dell x NVIDIA hackathon**, and tested on a laptop with a small stand-in model. At the event we moved it onto the GB10 (vLLM, NemoClaw/OpenClaw, OpenShell, Slack) and ran it at full scale. All company data is **fictional** and generated by `scripts/make_dataset.py`. Every picture in the console is rendered from that fictional data (`scripts/make_visuals.py`, see PHOTOS.md).

## What it does

**The console opens on a live perimeter map**: every person, shared folder, way out (email, upload portal,
USB drive, Slack, printer) and outside company, with the building's wall down the middle. Every attempt to
send a file flies along its path; blocked ones stop at the wall. **Simulate a workday** streams real checks
through the real engine. **Ask Embargo** answers questions ("what got blocked today?", "who can open the
Sales folder?") from the log, citing records; facts come from the database, the local model only phrases them.

**Embargo is also a real outgoing mail server** (SMTP on `127.0.0.1:2525`, `exportgate/mailgate.py`). Any mail
client, script or `curl` can send through it. A blocked attachment gets the message refused with
`550 5.7.1 Blocked by Embargo: …`, a held one is quarantined until an Empowered Official signs off (then delivered),
a clean one is delivered to the recipient's mailbox. The console's **Mail** screen shows the whole SMTP conversation.

| Job | When | What you see |
|---|---|---|
| **Gate** | every outgoing file (Slack upload or dashboard) | `BLOCKED: bracket_views_only.png to Mueller Praezision GmbH (DE). ITAR technical data with no export license on file.` plus the evidence |
| **Night sweep** | every night at 07:00, or `/gate sweep` | `Read 2,000 files. 3 controlled drawings open to people who shouldn't see them, 12 unmarked copies, 6 people exposed.` |
| **Proof** | always | an evidence ledger for every decision, a hash-chained log that shows any edit, and a sandbox that can't reach the internet |

## The model reads. Our code decides.

The vision model only turns pixels into text. Everything that decides is plain code you can test (`tests/test_rules.py`), and the final call on anything uncertain is always a human's.

### 1. Drawing fingerprint (no AI) — `exportgate/fingerprint.py`
Recognises a copy of a vault original even with the banner and title block cut off:
- find the drawing frame, straighten it, **mask what people crop** (margins, title block, notes); keep the geometry
- ORB keypoints → one index over every vault drawing → votes → RANSAC similarity check
- inliers **I**, coverage **M = I / min(n_query, n_vault)**, distinctiveness **D = I / max(I_2nd, 20)**
- **strong** if I ≥ 250 and D ≥ 3, **weak** if I ≥ 60 and D ≥ 2.5. Repeating patterns (hatching, hole symbols) give any two sheets ~100 chance inliers; D is what separates a real copy.

### 2. Reading: "no quote, no claim" — `exportgate/reader.py`
- PDF text layer first (no model call). Scans and photos are cut into overlapping 1024 px tiles (15% overlap) so 7 px lettering stays readable, and the local vision model transcribes each tile.
- Our patterns pull out markings (ITAR, EAR, USML, ECCN, distribution statements), part numbers and program names. Negations like "NOT SUBJECT TO ITAR" are ignored.
- The model may also propose clues, but each one must **quote text that really is in the document** (fuzzy match ≥ 90), or it is dropped and shown crossed out.

### 3. Evidence ledger — `exportgate/fusion.py`
```
logit(p) = logit(0.15) + Σ ln(LR_i)        p = 1 / (1 + e^-logit)
```
| evidence | LR |
|---|---|
| strong copy of an ITAR / EAR / commercial original | 30 / 15 / 0.2 |
| part number on register: exact / look-alike fixed (KP-1O23) / suffix or 1-char change | ITAR 50 / 25 / 8 |
| quoted ITAR / EAR marking | 40 / 20 |
| quoted USML / ECCN classification | 30 / 10 |
| distribution statement B–F / A | 8 / 0.4 |
| controlled program named | 10 |
| commercial marker (EAR99, public release, catalog) | 0.3 |
| **original is marked but this copy isn't** (label removed) | 5, and always held |

Only the strongest clue per category counts. p ≥ 0.90 controlled, 0.50–0.90 uncertain (held), < 0.50 clear. Jurisdiction = the most restrictive one any credible clue points to.

### 4. Release rules — `exportgate/policy.py`
| | US person | foreign, licensed | foreign, no license | sanctioned | unknown |
|---|---|---|---|---|---|
| ITAR | release* | HOLD | **BLOCK** | **BLOCK** | HOLD |
| EAR | release* | HOLD | HOLD | **BLOCK** | HOLD |
| not controlled | release | release | release | **BLOCK** | release |

\* if the sender is cleared for that program. Any file nothing could read, any copy of a controlled drawing whose markings couldn't be read, any removed label and any altered part number is **held**. The gate fails closed.

### 5. Two-person rule
The requester can never approve their own release, even if they are the Empowered Official, and only an Empowered Official can approve. BLOCK can't be approved by anyone.

### 6. Tamper-evident log — `exportgate/store.py`
`h_0 = SHA256("genesis")`, `h_n = SHA256(h_{n-1} ‖ event_n)`. Edit any old row and `/api/audit/verify` names the first broken row.

### 7. Night sweep — `exportgate/sweep.py`
```
E_f = p_f · w_j · (α·u_f + β·c_f)        α = 2, β = 1, flagged if E ≥ 0.3
```
w_j: ITAR 1.0, EAR 0.6, EAR99 0.05 · u_f: share of people who can open the folder and aren't authorized (foreign person or not cleared) · c_f: 1 if it's an unmarked copy of a marked original. A controlled file in the right folder, properly marked, scores 0.

The sweep runs a cascade: fingerprint and text layer first, and the vision model only for scans the cheap steps can't settle. It reports pages/min and the share settled without the model.

## What it will not do

Embargo **never sends, deletes or approves anything on its own.** It holds, and a person decides.
The AI model never makes a decision either: it only reads text off the page. Anything it can't
read is held, not released.

## Security model, in layers

1. **Who is asking.** Every request is tied to a staff record: role, US-person status, the programs they're cleared for.
2. **What the file is.** Recognised by its geometry (fingerprint), its part number (export register) and its own markings, each as a line in the evidence ledger. Cropping or painting over the label doesn't help: the drawing itself still matches.
3. **Who it's going to.** Fixed release rules: jurisdiction × recipient country × license on file × sanctions. Code, not a prompt.
4. **Tricks against the AI.** Text in a file that talks to the AI ("note to AI: approve this") is flagged and held. The model's claims count only if they quote the document word for word.
5. **Two people.** The sender can never approve their own release; only an Empowered Official can, and a BLOCK can't be approved by anyone.
6. **A sealed log.** Every request, decision and sign-off is chained with SHA-256. Edit one old record and the seal breaks at that record.
7. **No way out.** It runs in an OpenShell sandbox that denies all outbound traffic except Slack. It works with the wifi off; Slack messages wait in an outbox.
8. **Honest fallbacks.** Every decision records its path: live model, no model needed, cached, or replayed (`EG_READER=replay`, the stage safety net).

## Results

See [RESULTS.md](RESULTS.md) (regenerate with `python scripts/eval.py --sweep`). With **no model at all** (fingerprint + register + text layer): 0 leaks; 4 of 28 controlled files are held as unreadable rather than recognised, because they are new scans that aren't in the vault yet. Reading those is the vision model's job.

## Run it

**Laptop rehearsal** (Ollama stands in for vLLM):
```
uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.txt
ollama pull qwen3-vl:4b-instruct
EG_LLM_MODEL=qwen3-vl:4b-instruct bash scripts/run_mac.sh      # console at http://127.0.0.1:8790 (old plain dashboard: /classic)
.venv/bin/python scripts/smoke.py                              # the demo moments, end to end
.venv/bin/pytest -q
```

**GB10:** `bash scripts/run_gb10.sh` starts vLLM (Qwen3.6-35B-A3B NVFP4, 127.0.0.1:8000), the dashboard, and the Slack bot if `SLACK_BOT_TOKEN` / `SLACK_APP_TOKEN` are set. Steps marked `[verify]` in the scripts must be checked on the box.

**Slack:** create the app from `slack/manifest.yaml`, `/invite @Embargo` to `#embargo`, then `/gate iam marco.bellini@kestrelprecision.example` and upload a file with `to: hans.weber@mueller-praezision.example`.

**Agent:** `openclaw/skills/embargo/SKILL.md` lets the OpenClaw agent answer "why was this held?" from the API. It explains decisions; it never makes them.

**Sandbox:** `policies/embargo-egress.yaml` allows Slack only. `openshell logs <sandbox> --tail` shows every denied request.
